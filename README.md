# 地域限定旅行業務取扱管理者 過去問クイズ

令和5年度・令和6年度・令和7年度の本試験問題（全177問）を、解説つきで解けるWebアプリです。
`index.html` の1ファイルだけで動きます（サーバー不要・オフラインでも動作）。

## 公開のしかた（GitHub Pages）

1. GitHub で新しいリポジトリを作る（Public）
2. `index.html` をアップロードしてコミット
3. Settings → Pages → Build and deployment の Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 収録内容

- 科目1 旅行業法及びこれに基づく命令（各年25問）
- 科目2 旅行業約款、運送約款及び宿泊約款（各年24問）
- 科目3 国内旅行実務（各年10問）

学習記録（解答済み・正答率・まちがえた問題）は、閲覧した端末のブラウザに保存されます。
